# Attacker vs Defender — [Steam]

## The system
-I picked my steam account/games i play.

## Attacker view
-The attacker would advertise a game that they think I would like or play because hes seen my game library if hes successful then I would download this game thinking it was a safe copy of the game but actually what it is is the game but it also installed spyware in my computer so now the attacker can see what im doing on my pc.
Now what the attacker would gain from this is valuable information for example if he sees me put my bank account login info.


## Defender view
-My defence to this attack would be installing or having a firewall that monitors and reports suspicious looking files im trying to download or checking if the game has reviews that say that this has happened to them aswell that way I don't install it in the first place.
If the hacker wants to bypass this defence he would need like a tool or software that can go thru my firewall or try to make fake reviews saying that the game is "safe".
My defence is somewhat strong but a skilled attacker can definitely bypass my firewall especially if the firewall isn't trusted or weak.


## CIA angle
-I would say that this attack falls under confidentiality because if the hacker succeeds he gets my confidential information such as bank login info or just any login info in general.


## What I'm changing this week
